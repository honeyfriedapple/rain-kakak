# Website ulang tahun bertema hujan

File yang ada di sini:

- `index.html` kerangka halaman
- `style.css` tampilan dan warna
- `script.js` bagian yang bikin hujan dan interaksinya
- `isi.js` semua tulisan (doa, surat, kalimat merajut, penutup)

## Coba dulu di laptop

Klik dua kali `index.html`, nanti kebuka di browser. Pastikan semua file ada dalam satu folder yang sama.

## Cara upload ke GitHub Pages

1. Login ke GitHub, klik tombol **+** di kanan atas, lalu **New repository**.
2. Isi nama repo, misalnya `untuk-kakak`. Pilih **Public**, lalu **Create repository**.
3. Klik **uploading an existing file**, lalu drag semua file dari folder ini (bukan foldernya, tapi isinya).
4. Scroll ke bawah dan klik **Commit changes**.
5. Buka **Settings**, lalu **Pages**. Di bagian **Branch**, pilih `main` dan folder `/ (root)`, lalu **Save**.
6. Tunggu 1 sampai 2 menit. Link-nya akan muncul di halaman yang sama, bentuknya `username.github.io/untuk-kakak`.

Kalau akun GitHub yang dipakai akun pribadi, nama akun itu akan ikut kelihatan di link.

## Cara ganti tulisan

Buka `isi.js`, ubah teks di dalam tanda kutip, simpan. Kalau sudah di GitHub, klik file `isi.js`, klik ikon pensil, ubah, lalu **Commit changes**.

Untuk menambah doa, tambahkan satu baris baru di bagian `daftar` dengan format yang sama dan jangan lupa koma di akhir baris sebelumnya.

Bagian `dari` di surat sekarang berisi "Kami semua". Ganti kalau mau.

## Catatan kecil

- Suara hujan sengaja dibuat mati dari awal, jadi Kakak bisa menyalakannya sendiri lewat tombol di pojok kanan atas.
- Paling enak dibuka lewat HP.
- File ini boleh kamu hapus dari repo kalau tidak mau kelihatan.
